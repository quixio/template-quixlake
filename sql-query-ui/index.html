Compact Table

🗜️ File Optimization: Compact will merge small files and fix schema inconsistencies while preserving your existing partition structure.

  • Combines small files for better performance
  • Fixes schema mismatches using union_by_name
  • Preserves existing partition hierarchy
  • Does not change partition structure

Need to change partition structure? Use the "Repartition" feature instead.
